06 Always-on judgment

Voice

Sub-second decisions on the audio path — turn-taking, speak-up, and voice→action — so assistants can live in the room without a wake word or chaos.

  • Voice-driven computer use — ASR / dialogue state → click, type, scroll Choice (ears instead of pixels) Browser Use Cua computer-use
  • Secondary turn / end-of-utterance detect — Noul bolted onto an aggressive VAD or primary turn model
    Conceptual System One leaf (not a public Jev demo yet): stream VAD / primary EOU probabilities into state; ask a Noul like “has the user finished their turn?” and only then commit ASR→LLM. Cheap second opinion before the stack spends a frontier call.
  • Speak-up gate — should the bot interrupt / reply, with or without a wake word
    Conceptual System One leaf: Choice or Noul over stay silent / acknowledge / full reply, gated on confidence. Wake word optional — calibrated confidence is the gate. Pairs with confidence-routing patterns in TypeSafe docs.
    confidence routing
  • Group / multi-party bot — same gate unlocks a bot in a roomful of people
    Extension of the speak-up gate: in multi-speaker audio, decide whether this utterance is for the bot, whether interrupting helps, and whether to stay silent. Without it you need a wake word or you thrash the room.
