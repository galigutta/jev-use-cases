01 Smart if-statements

Smart workflow decisions

Fuzzy classify / route / score / branch inside ordinary software — where brittle rules fail and chat models are overkill.

  • Support triage — dept, urgency, frustration, refund, policy fit
  • Lead / ICP qualification — prospect vs spam vs applicant
  • Insurance FNOL — complexity, fraud signals → STP vs specialist
  • FinCrime / KYC — narrative risk, entity match, alert priority
  • Legal & compliance flags — missing clauses, prohibited claims
  • E-com listing normalize — attributes, counterfeit, review abuse
  • Returns / refund auto-approve — clear → auto; ambiguous → human
  • PR / alert / ticket ownership — team Choice + severity Score
  • Onboarding article match · feature-request extraction
  • Inbox / newsletter sort · sponsor-form screening
  • Home Assistant automations HA-Jev

04 Universal verification

Verify & guardrails

Score, judge, and gate prompts, traces, tool calls, drafts, and claims — at a fraction of the LLM call you’re protecting.

  • Jailbreak / prompt-injection detection on LLM I/O
  • Citation & groundedness — does the passage support the claim?
  • Pre-send draft checks — contradiction, false refund vs account
  • Shell / tool-call risk — read-only vs reversible vs irreversible
  • Agent safety monitor — escalate suspects to a bigger model
  • Writing defect / style lints · semantic CI rules
  • Brand / pre-publish CMS checks
  • Ad brand-safety & claim compliance

Shared machinery

Not extra use cases — the patterns every leaf is built from.

Speculative fan-out

Ask ten questions in one call. Code keeps what mattered. Time barely moves.

Confidence gates

Act above the threshold. Human or LLM below. Calibrated belief as architecture.

Cascade

Jev → pure code → specialist LLM → human. Pay for intelligence only when you need it.

Retrieve, then judge

Fetch precisely. Hand Jev tight state. Accuracy is a function of what you allow it to see.

Composite scoring

Atomic Scores + your weights. Re-weight in code, not in a prompt rewrite.

Out of scope

  • Generating text, code, or rationales
  • Arithmetic, counting, date math
  • Open answers outside a declared option set
  • Perception / control-rate loops (pixels, 500 Hz flight)
